# TechPubs Toolpack

A collection of Python automation tools built for technical publications, document quality, and workflow management.

## Tools

| Repo | File(s) | Description |
|------|---------|-------------|
| [pdf-comparison-tool](https://github.com/pavanivislavsth-alt/pdf-comparison-tool) | `Updated_Final_PDFCompare.py` | Side-by-side PDF diff with highlighted changes |
| [pdf-trademark-checker](https://github.com/pavanivislavsth-alt/pdf-trademark-checker) | `Updated_TradeMark.py` | Validates ™ / ® symbols in PDF documents |
| [svg-converter](https://github.com/pavanivislavsth-alt/svg-converter) | `SVG3converter.py` | Converts Visio/EMF/WMF to SVG |
| [register-manual-creator](https://github.com/pavanivislavsth-alt/register-manual-creator) | `Updated_RegisterManual.py` | XML register manual generator |
| [video-to-ppt](https://github.com/pavanivislavsth-alt/video-to-ppt) | `video2ppt.py` | Capture video frames → PowerPoint |
| [package-diagram-search](https://github.com/pavanivislavsth-alt/package-diagram-search) | `Updated_PCKGdiagram.py` | Cypress → Infineon package number lookup |
| [pdf-broken-link-checker](https://github.com/pavanivislavsth-alt/pdf-broken-link-checker) | `PDFbrokenlink.py` | Detects broken hyperlinks in PDFs |
| [video-to-text](https://github.com/pavanivislavsth-alt/video-to-text) | `Video2Text4.py` | Transcribes video audio to text |
| [jira-dashboard-fetcher](https://github.com/pavanivislavsth-alt/jira-dashboard-fetcher) | `JiraDashboardFetching.py` | Exports Jira dashboard grid data to Excel |
| [ecn-scraper](https://github.com/pavanivislavsth-alt/ecn-scraper) | `Fetching_1702.py` | Batch ECN metadata scraper |

## Stack
- Python 3.x · PyQt5 · Selenium · PyMuPDF · openpyxl / pandas · OpenCV · python-pptx
